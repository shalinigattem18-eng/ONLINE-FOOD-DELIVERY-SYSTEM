🍔 Online Food Delivery System

A simple web-based Online Food Delivery System developed using HTML, CSS, and JavaScript.

Features

- User Signup and Login
- Admin Login
- Food browsing and search
- Add to Cart
- Place Orders
- View Orders
- Admin can add food items
- Local Storage for data
- Module-wise navigation using JavaScript
